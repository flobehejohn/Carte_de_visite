# Contribuer

Merci de contribuer à ce dépôt.

Ce projet vise un niveau de qualité reproductible côté front, serveur et CI. Toute contribution doit rester alignée avec les principes en place : traçabilité, contrats explicites, tests déterministes, et exécution CI lisible.

## Prérequis

- Node.js 22+
- npm 11 recommandé
- PowerShell 7 recommandé pour les scripts `pwsh`
- Git

## Installation

```bash
npm ci
```
